# x402 + ChimiaClaw (DAO revenue path)

## Why

x402 revives HTTP 402 Payment Required so agents can pay USDC for APIs without accounts or API keys. ChimiaClaw already has a science service market spine (quote → escrow → result → release). x402 is the **HTTP cashier** for that spine.

## Public surface (brand)

| Surface | URL | Notes |
|---------|-----|--------|
| DAO website | https://www.chimiadao.io | Canonical human front door (Next.js / Vercel) |
| Science market UI | `www.chimiadao.io/agents` (recommended) | Catalog + try MolADT + agent docs — **part of the existing site** |
| Agent API | `api.chimiadao.io` (recommended) | x402 cashier (`services/api-gateway`) |

Do not ship a second public brand for “OpenAgents.” ChimiaClaw is the runtime; ChimiaDAO is the product face.

Treasury address and live facilitator are **not required** to ship the site section in `free` or `stub` mode. They are only required for `X402_MODE=live` USDC settlement.

## Settlement honesty

| Mode | Funds | Use |
|------|-------|-----|
| Free | none | Local UI |
| Stub | none | Demo 402 loop (`PAYMENT-SIGNATURE: stub`) |
| Live | USDC on Base | Production DAO revenue |

Never claim live settlement without `X402_MODE=live`, a real `pay_to`, and facilitator verification.

## Operator commands

```bash
# Signed stub settlement trail (Rust)
cargo run -p chimiaclaw-cli -- x402-demo

# Catalog JSON
cargo run -p chimiaclaw-cli -- x402-catalog --pay-to 0xYourTreasury

# Science payload used by the gateway
cargo run -p chimiaclaw-cli -- moladt-api --smiles O --no-worker

# Gateway
cd services/api-gateway && npm install && npm run dev
```
